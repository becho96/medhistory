# Дизайн-гайд: Рефакторинг веб-версии медицинского сервиса

## О документе

Этот гайд предназначен для UI/UX-дизайнера, выполняющего рефакторинг веб-приложения медицинского сервиса для хранения и анализа медицинских документов. Рекомендации основаны на анализе дизайн-системы **Plane** (open-source project management platform, 46 000+ GitHub stars) — одного из лучших примеров современного SaaS-интерфейса.

**Референсный проект:** [github.com/makeplane/plane](https://github.com/makeplane/plane)
Путь к дизайн-токенам: `packages/tailwind-config/variables.css`
Путь к UI-компонентам: `packages/ui/src/`

## 1. Типографика

### Шрифт

Основной шрифт для heading и body: **Inter Variable**.
Моноширинный шрифт для кода и технических данных: **IBM Plex Mono**.

```css
--font-heading: "Inter Variable", ui-sans-serif, system-ui, sans-serif;
--font-body: "Inter Variable", ui-sans-serif, system-ui, sans-serif;
--font-code: "IBM Plex Mono", ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace;
```

**Почему Inter:** нейтральный, высокочитаемый, оптимизирован для экранов, имеет переменное начертание и поддерживает все веса от 100 до 900. Для медицинского сервиса критична читаемость мелкого текста — Inter справляется с этим отлично.

### Размерная шкала

Plane использует нестандартную шкалу из 14 размеров, оптимизированную для плотного интерфейса:

| Токен | Размер | Применение в медсервисе |
|-------|--------|------------------------|
| `text-9` | 9px (0.5625rem) | Метки на графиках, timestamps |
| `text-10` | 10px (0.625rem) | Вспомогательные подписи |
| `text-11` | 11px (0.6875rem) | Кнопки SM, бейджи, теги документов |
| `text-12` | 12px (0.75rem) | Caption, мета-данные документов |
| `text-13` | 13px (0.8125rem) | **Основной размер интерфейса**, кнопки, списки |
| `text-14` | 14px (0.875rem) | Body-текст, описания |
| `text-16` | 16px (1rem) | Крупный body, подзаголовки секций |
| `text-18` | 18px (1.125rem) | Подзаголовки |
| `text-20` | 20px (1.25rem) | H4 — заголовки карточек документов |
| `text-24` | 24px (1.5rem) | H3 — заголовки секций |
| `text-28` | 28px (1.75rem) | H2 — заголовки страниц |
| `text-32` | 32px (2rem) | H1 — главные заголовки |
| `text-40` | 40px (2.5rem) | Display — промо/dashboard |

### Весовая шкала

```css
--font-weight-light: 300;     /* Декоративные элементы */
--font-weight-regular: 400;   /* Body-текст */
--font-weight-medium: 500;    /* Основной вес для UI (кнопки, навигация) */
--font-weight-semibold: 600;  /* Заголовки секций, акценты */
--font-weight-bold: 700;      /* Заголовки страниц */
--font-weight-heavy: 800;     /* Display-элементы, hero */
```

### Heading-токены

Все заголовки: `line-height: 1.2`, `letter-spacing: 0`. Каждый уровень имеет 4 варианта по весу: regular, medium, semibold, bold. Пример:

```css
--text-h1-semibold: 2rem;         /* 32px */
--text-h1-semibold--line-height: 1.2;
--text-h1-semibold--font-weight: 600;
```

### Letter-spacing

```css
--tracking-extra-tight: -0.025rem;  /* Display-заголовки */
--tracking-tight: -0.05rem;         /* Не используется в heading по умолчанию */
--tracking-default: 0;              /* Все heading и body */
--tracking-wide: 0.05rem;           /* Uppercase-лейблы */
```

### Рекомендации для медсервиса

- **13px Medium** — основной размер для всех элементов интерфейса (списки документов, кнопки, навигация)
- **14px Regular** — для длинных текстов (описания документов, результаты анализа, заключения)
- **IBM Plex Mono** — для медицинских кодов, ID документов, дат в строгом формате
- Плотный интерфейс медсервиса хорошо работает с 13px, а не с привычных 16px — это позволяет показать больше данных на экране

## 2. Цветовая система

### Философия

Plane использует **семантическую систему токенов** в формате OKLCH с поддержкой 4 тем: Light, Dark, Light High-Contrast, Dark High-Contrast. Цвета определяются не напрямую, а через уровни абстракции:

```
Базовые цвета (oklch) → Neutral/Brand/Status шкалы → Семантические токены → Tailwind-классы
```

### Нейтральные цвета (Light mode)

Plane строит UI на серой шкале из 14 оттенков. Для медсервиса это критично — большая часть интерфейса нейтральная, акценты минимальны.

```css
--neutral-white: oklch(1 0 0);                    /* #ffffff — чистый белый */
--neutral-100: oklch(0.9848 0.0003 230.66);       /* ~#f8f9fa — легчайший серый */
--neutral-200: oklch(0.9696 0.0007 230.67);       /* ~#f1f2f4 */
--neutral-300: oklch(0.9543 0.001 230.67);        /* ~#eaecef — canvas (фон приложения) */
--neutral-400: oklch(0.9389 0.0014 230.68);       /* ~#e3e5e8 */
--neutral-500: oklch(0.9235 0.0017 230.69);       /* ~#dcdee2 */
--neutral-600: oklch(0.8925 0.0024 230.7);        /* ~#cfd2d6 */
--neutral-700: oklch(0.8612 0.0032 230.71);       /* ~#c2c5ca */
--neutral-800: oklch(0.6668 0.0079 230.82);       /* ~#868b93 — disabled text */
--neutral-900: oklch(0.6161 0.0092 230.87);       /* ~#737982 — placeholder */
--neutral-1000: oklch(0.5288 0.0083 230.88);      /* ~#5a5f67 — tertiary text */
--neutral-1100: oklch(0.4377 0.0066 230.87);      /* ~#3f4249 — secondary text */
--neutral-1200: oklch(0.2378 0.0029 230.83);      /* ~#1b1d21 — primary text */
--neutral-black: oklch(0.1472 0.0034 230.83);     /* ~#0d0e10 */
```

**Нюанс:** оттенок серого — холодный (hue 230, синеватый). Это придаёт интерфейсу профессиональный, «медицинский» вид. Не используйте тёплый серый.

### Brand (акцентный цвет)

```css
--brand-default: oklch(0.4799 0.1158 242.91);     /* Синий ~#3b6bc4 — основной акцент */
--brand-100: oklch(0.9847 0.0083 236.56);          /* Светлейший фон акцента */
--brand-700: oklch(0.6766 0.1665 243.91);          /* Насыщенный синий */
--brand-1200: oklch(0.2093 0.0438 234.02);         /* Самый тёмный */
```

**Для медсервиса:** синий — стандарт для медицинских приложений (доверие, спокойствие, профессионализм). Brand-default Plane попадает в правильный диапазон.

### Статусные цвета

```css
/* Success (Green) — документ загружен, анализ завершён */
--green-700: oklch(0.632 0.186 147.37);           /* Primary success bg */
--green-100: oklch(0.9819 0.0181 155.83);          /* Subtle success bg */

/* Warning (Amber) — срок действия документа истекает */
--amber-600: oklch(0.7724 0.173 65.37);            /* Primary warning bg */
--amber-100: oklch(0.9869 0.0214 95.28);           /* Subtle warning bg */

/* Danger (Red) — ошибка, критический результат анализа */
--red-700: oklch(0.583 0.239 28.48);               /* Primary danger bg */
--red-100: oklch(0.9705 0.0129 17.38);             /* Subtle danger bg */
```

### Extended-цвета для лейблов

Plane предоставляет 8 цветовых палитр для лейблов, каждая с вариантами bg, bg-strong, hover, icon, text, border, focus: **purple, orange, crimson, emerald, pink, yellow, indigo, grey**.

**Применение в медсервисе:** категоризация документов (анализы — emerald, рецепты — purple, направления — indigo, снимки — orange, заключения — pink).

### Семантические фоновые токены

```css
/* Многослойная система фонов */
--bg-canvas: var(--neutral-300);           /* Фон всего приложения */
--bg-surface-1: var(--neutral-white);      /* Основные панели, карточки */
--bg-surface-2: var(--neutral-100);        /* Вложенные панели */
--bg-layer-1: var(--neutral-200);          /* Элементы на surface */
--bg-layer-1-hover: var(--neutral-300);    /* Hover-состояние */
--bg-layer-1-active: var(--neutral-400);   /* Active/pressed */
--bg-layer-1-selected: var(--neutral-400); /* Выбранный элемент */
--bg-layer-2: var(--neutral-white);        /* Второй уровень вложенности */
--bg-layer-3: var(--neutral-300);          /* Третий уровень */
```

### Семантические текстовые токены

```css
--txt-primary: var(--neutral-1200);        /* Основной текст */
--txt-secondary: var(--neutral-1100);      /* Второстепенный */
--txt-tertiary: var(--neutral-1000);       /* Третичный */
--txt-placeholder: var(--neutral-900);     /* Placeholder в формах */
--txt-disabled: var(--neutral-800);        /* Заблокированный */
--txt-accent-primary: var(--brand-default); /* Акцентный (ссылки, действия) */
--txt-on-color: var(--neutral-100);        /* Текст на цветном фоне */
--txt-inverse: var(--neutral-white);       /* Инвертированный */
```

### Семантические border-токены

```css
--border-subtle: var(--neutral-400);       /* Лёгкие разделители */
--border-subtle-1: var(--neutral-500);     /* Чуть заметнее */
--border-strong: var(--neutral-600);       /* Заметные границы */
--border-strong-1: var(--neutral-700);     /* Сильные границы */
--border-accent-strong: var(--brand-default); /* Акцентная граница */
```

### Рекомендации для медсервиса

- Canvas (#eaecef) → Surface-1 (white) → Layer — это даёт мягкое разделение зон без резких контрастов
- Для медицинских результатов с отклонениями от нормы используйте `danger-subtle` (фон) + `danger-primary` (текст), не просто красный цвет
- Лейблы документов — extended-палитра с 8 цветами покрывает все типы медицинских документов
- Поддержка High-Contrast темы критична для accessibility в медицинском софте

## 3. Компонентная система

### Кнопки

Plane реализует 11 вариантов кнопок × 4 размера. Для медсервиса рекомендуется сокращённый набор:

**Основные варианты:**

| Вариант | Стиль | Применение в медсервисе |
|---------|-------|------------------------|
| `primary` | Заливка brand-цветом, белый текст | «Загрузить документ», «Начать анализ» |
| `neutral-primary` | Белый фон, серая граница | «Отмена», «Назад», вторичные действия |
| `outline-primary` | Прозрачный фон, brand-граница | «Скачать», «Поделиться» |
| `danger` | Красная заливка | «Удалить документ» |
| `link-primary` | Без фона, brand-текст | Inline-ссылки, «Подробнее» |

**Размеры:**

```css
sm: px-3 py-1.5 text-11 rounded-sm    /* Компактные действия в таблицах */
md: px-4 py-1.5 text-13 rounded-sm    /* Основной размер */
lg: px-5 py-2 text-13 rounded-sm      /* Заметные действия */
xl: px-5 py-3.5 text-13 rounded-sm    /* CTA, hero-действия */
```

**Состояния:** default → hover (opacity 80%) → pressed (focus) → disabled (layer-1 bg + placeholder text)

### Полный список UI-компонентов

Из `packages/ui/src/`:

**Навигация и структура:** breadcrumbs, tabs, header, control-link, link
**Ввод данных:** form-fields, color-picker, dropdown, dropdowns, auth-form, oauth
**Отображение данных:** tables, badge, tag, avatar, progress, typography, card
**Обратная связь:** modals, popovers, tooltip, loader, spinners
**Интерактив:** button, favorite-star, drag-handle, drop-indicator, sortable, collapsible, scroll-area, content-wrapper, row

### Адаптация для медсервиса

**Необходимые компоненты (из Plane):**
- `tables` — для списков документов с сортировкой и фильтрацией
- `badge` + `tag` — для типов документов, статусов анализа
- `modals` — для просмотра документов, подтверждения действий
- `tabs` — для переключения между видами (список / карточки / timeline)
- `form-fields` — для загрузки документов, фильтров поиска
- `breadcrumbs` — для навигации в глубокой структуре документов
- `sortable` + `drag-handle` — для организации документов в папках
- `progress` — для отображения прогресса загрузки/анализа
- `tooltip` — для пояснений к медицинским терминам

**Дополнительные компоненты для медсервиса:**
- Document card — карточка документа (превью, тип, дата, статус)
- Search bar с фильтрами — полнотекстовый поиск по содержимому документов
- Timeline view — хронология медицинских документов пациента
- Analysis result panel — панель результатов AI-анализа
- Document viewer — встроенный просмотрщик PDF/изображений

## 5. Spacing и сетка

### Базовая единица

Plane использует стандартную сетку Tailwind (4px base): `0.5 = 2px`, `1 = 4px`, `1.5 = 6px`, `2 = 8px`, `3 = 12px`, `4 = 16px`, `5 = 20px`, `6 = 24px`, `8 = 32px`.

### Паттерны отступов

```css
/* Кнопки */
sm: padding 12px 6px
md: padding 16px 6px
lg: padding 20px 8px
xl: padding 20px 14px

/* Карточки/секции */
padding: 16px (стандартно)
gap между элементами: 8-12px

/* Sidebar items */
padding: 8px 12px
gap: 2-4px
```

### Border-radius

Plane использует `rounded-sm` (2px) повсеместно — минимальное скругление. Это создаёт строгий, профессиональный вид, уместный для медицинского ПО.

## 6. Анимации и переходы

### Из `animations.css`:

```css
slide-up: translateY(10px) → translateY(0), 0.25s ease-out
slide-in-from-bottom: translateY(100%) → translateY(0)
slide-in-from-top: translateY(-100%) → translateY(0)
fade-in: opacity 0 → 1, 0.25s ease-out
fade-out: opacity 1 → 0, 0.2s ease-out
```

### Рекомендации

- Длительность: **0.2–0.25s** для всех UI-переходов
- Easing: **ease-out** (быстрый старт, плавное замедление)
- Модальные окна: slide-up + fade-in одновременно
- Detail panel: slide-in-from-right
- Hover-эффекты: transition-all (цвет фона, тени)
- Не используйте bounce или spring — в медицинском контексте это неуместно

## 8. Accessibility

### Из дизайн-системы Plane

- Поддержка **High-Contrast** тем (light + dark)
- Кнопки: `cursor: pointer` только для не-disabled
- Placeholder: семантический токен `text-placeholder` с достаточным контрастом
- `focus` состояния для всех интерактивных элементов
- `font-variant-ligatures: none` — предотвращает проблемы с чтением
- `-webkit-font-smoothing: antialiased` — чёткий рендеринг текста

### Дополнительно для медсервиса

- Минимальный контраст текста: WCAG AA (4.5:1 для нормального, 3:1 для крупного)
- Не полагаться только на цвет для передачи информации — добавлять иконки и текст
- Поддержка screen readers: aria-labels для всех иконочных кнопок
- Keyboard navigation: tab-order, focus-visible стили

### Список документов

```

│ 📄 Общий анализ крови          [Анализ]  2025-03-15  ✅ │
```

- Каждая строка: `bg-surface-1`, `border-subtle` снизу
- Hover: `bg-layer-1-hover`
- Тег типа документа: `badge` с extended-цветом

### Поиск

- Полнотекстовый поиск: крупное поле в toolbar
- Фильтры: dropdown с мульти-выбором (тип документа, период, статус, клиника)
- Результаты: highlighting найденных фрагментов с `bg-accent-subtle`

### Просмотр документа

- Левая панель: встроенный viewer (PDF/изображение)
- Правая панель: метаданные + результаты AI-анализа
- Действия сверху: «Скачать», «Поделиться», «Удалить», «Запустить анализ»

### Dashboard

- Метрики: количество документов, последний визит, ближайшие напоминания
- Timeline: хронологическая лента всех медицинских событий
- Quick actions: «Загрузить документ», «Найти», «Последние»

## 10. Приоритетные цвета

```css
--priority-urgent: oklch(0.5798 0.1766 26.99);    /* Красный — критический результат */

--priority-low: oklch(0.579 0.1807 262.31);        /* Синий — информационный */
```
