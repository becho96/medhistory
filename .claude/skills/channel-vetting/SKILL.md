# Оценка Telegram-канала для закупки рекламы

Методика проверки канала перед оплатой размещения. Цель — не «канал
большой», а «канал приведёт целевых пользователей по приемлемой цене».

## Главное правило

**Цифры берутся ТОЛЬКО из карточки конкретного канала** — вкладка
«Полная статистика» на telega.in или страница канала на TGStat.
Каталожные сводки, выдача поиска, сторонние подборки — НЕ источник:
там числа устаревшие и часто перепутаны. Если данных не хватает —
запросить у пользователя скриншот «Полной статистики», не угадывать.

## Шаг 1. Собрать данные

Из «Полной статистики» нужны:

- Подписчики: всего + изменение за вчера / неделю / месяц
- Просмотров на пост (средний охват)
- ERR (Engagement Rate by Reach), %
- ER, % — общий («ER за 24 часа» с карточки ненадёжен, см. Шаг 2)
- Emoji Reaction Rate рекламных постов, %
- Среднее число рекламных размещений в месяц
- Пол аудитории (доля женщин/мужчин)
- Возраст канала, всего публикаций
- Повторные заказы на telega.in (если есть)
- Цена размещения (формат 1/24) — из карточки канала

## Шаг 2. Прогнать по чек-листу

| Метрика | Норма | Плохо |
|---|---|---|
| Подписчики за месяц | рост или ≈0 | падение |
| Read rate = просмотры / подписчики | ≥ 15–20% | < 10% |
| ER (общий) | > 1,5–2% | < 1% |
| Emoji Reaction Rate реклам. постов | > 0 | 0% |
| Реклам в месяц | ≤ 8–10 | > 12 |
| Пол аудитории | данные есть и совпадают с ЦА | данных нет / не та ЦА |
| Возраст канала | > 6 мес | < 3 мес |

Read rate считать самому: `просмотры на пост / число подписчиков`.
ERR с карточки — близкая величина, но read rate нагляднее.

Метрику «ER за 24 часа» в расчёт НЕ брать: она часто показывает 0,0
как артефакт (нет свежего поста в окне), а не из-за мёртвой аудитории.
Опираться на общий ER и динамику подписчиков.

## Шаг 3. Авто-дисквалификация

Канал НЕ берём (любого одного достаточно), если:

- подписчики устойчиво и резко падают (> ~3% в месяц) — канал теряет аудиторию;
- нет данных о поле аудитории, а ЦА гендерно-специфична (напр. мамы);
- реклам > 12 в месяц — пост утонет в рекламном шуме;
- read rate < 8% — аудитория не читает (накрутка/боты).

## Шаг 4. Экономика

**CPM** (цена за 1000 просмотров):

```
CPM = цена размещения / (просмотры на пост / 1000)
```

Норма для ниши «мамы / дети»: ~200–500 ₽. Сильно выше — торговаться
или отказаться.

**Прогноз целевых пользователей.** Воронка для медицинского продукта
(регистрация + загрузка документа — «тяжёлая» цель):

- просмотр → клик по лендингу: 1–3%
- клик → регистрация: 15–30%
- регистрация → загрузка документа: 40–60%
- итог просмотр → целевой пользователь: **0,3–0,8%**

```
целевые юзеры ≈ просмотры на пост × 0,003…0,008
CAC ≈ цена размещения / целевые юзеры
```

Ориентир CAC кампании: бюджет / цель. Для текущей кампании —
30 000 ₽ / 200 = **150 ₽** за пользователя. Прогнозный CAC канала
сравнивать с этим порогом.

## Шаг 5. Вердикт

Выдать таблицу «метрика / норма / факт / ✓✗», затем итог:

- **Брать** — чек-лист пройден, CPM в норме, прогнозный CAC ≤ ориентира.
- **Торговаться** — метрики хорошие, но CPM/CAC выше нормы: запросить
  скидку или меньший формат, иначе понизить приоритет.
- **Не брать** — есть авто-дисквалификатор или CAC кратно выше ориентира.

Всегда указывать прогноз: ожидаемый охват, целевые юзеры, CAC. Помнить,
что одно размещение в среднем канале — это десятки пользователей, не
сотни; задача пилота — измерить CAC, а не закрыть всю цель.

## Пример (реальные данные)

Канал «Подскажите | Пособия», из «Полной статистики»:
8,0K подписчиков (−101 за месяц), 546 просмотров/пост, ERR 6,8%,
7 реклам/мес, пол аудитории «--».

Разбор:
- read rate = 546 / 8000 = **6,8%** → < 8% → авто-дисквалификация
- пол аудитории неизвестен → нельзя подтвердить, что ЦА — мамы
- прогноз: 546 × 0,005 ≈ **3 целевых юзера** с размещения

**Вердикт: не брать.** Аудитория не читает посты, охват мизерный —
сигнал по CAC будет статистически пустым при любой цене.
